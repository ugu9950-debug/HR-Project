# 퇴직율 분석 대시보드

`퇴직율_분석_템플릿_2022-2026.xlsx` 의 분석 구조를 그대로 옮긴 웹 대시보드입니다.

> ### ⚠ 이 폴더는 공개 저장소에 올리지 마세요
> 대시보드에는 본부별 재직인원·퇴직율 같은 **내부 인사 데이터**가 들어 있고,
> 원본 워크북에는 **임직원 성명이 포함된 개인정보**가 있습니다.
> `HR-Project` 저장소는 현재 **public** 입니다. 푸시 전에 저장소를 private 으로 바꾸거나,
> 이 폴더를 별도 비공개 저장소로 분리하세요.
> `.gitignore` 가 `*.xlsx` 를 제외하고 있으니 **워크북 자체는 커밋되지 않습니다.**

## 데이터 갱신

워크북을 최신화한 뒤 아래 한 줄이면 대시보드 숫자가 전부 바뀝니다.
**Node 18 이상만 있으면 되고, 설치할 패키지가 없습니다.**

```bash
node tools/build-dashboard-data.mjs 퇴직율_분석_템플릿_2022-2026.xlsx
```

`turnover_dashboard_prototype.jsx` 안의 `GENERATED-DATA` 구간만 교체하고,
정합성 검증 결과와 연도별 요약을 출력합니다. 검증에 실패하면 종료 코드 1을 반환합니다.

### 옵션

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--기준일 2026-08-25` | 재직자 근속·당해연도 기말의 기준일 | 워크북 `기준설정!C4`, 없으면 오늘 |
| `--연도 2024-2026` | 분석 기간 (현재 대시보드는 2024~2026) | 워크북 `기준설정!7행`, 없으면 최근 5년 |
| `--본부최소 5` | 연평균 재직인원이 이보다 작은 본부는 `기타(미매핑)` 로 합산 | 5 |
| `--교차표 12` | 본부 × 근속구간 교차표에 넣을 본부 수 | 12 |
| `--직급상세 20` | 직급 상세 표에 넣을 직급 수 | 20 |
| `--keep-reasons` | 퇴사사유가 비어 있어도 기존 사유 블록을 유지 (데모용) | 꺼짐 |
| `--out <경로>` | 교체할 JSX 경로 | `../turnover_dashboard_prototype.jsx` |
| `--dry-run` | 파일을 쓰지 않고 리포트만 출력 | 꺼짐 |

생성기는 **RawData 1행의 헤더 이름으로 열을 찾습니다.** 열 순서가 달라도,
raw 레이아웃이든 템플릿 레이아웃이든 동작합니다.
필수 열은 `본부` · `직급` · `입사일` · `퇴사일` 이고, `퇴사사유` 는 있으면 씁니다.
`기준설정` 시트가 있으면 근속구간 상한(I·J), 직급그룹 매핑(D·E), 사유구분(L·M)을 읽고,
없으면 템플릿 표준값으로 대체합니다.

## 미리보기 HTML 다시 만들기

```bash
npm install            # 최초 1회
node tools/build-preview.mjs
```

또는 `npm run build` 로 데이터 갱신 + HTML 빌드를 한 번에 실행합니다.

## 계산 정의 (템플릿과 동일)

```
퇴직율        = 해당 연도 퇴사자 수 ÷ 평균 재직인원
평균 재직인원 = (기초 재직인원 + 기말 재직인원) ÷ 2
기초 재직인원 = 1월 1일 시점 재직자
기말 재직인원 = 12월 31일 또는 데이터 기준일 시점 재직자
근속일수      = 퇴사자는 퇴사일 − 입사일, 재직자는 기준일 − 입사일
근속구간      = 상한(일) 이하를 만족하는 첫 구간
구성비        = 해당 연도 퇴사자 중 비율        (분모 = 퇴사자 수)
사유별 퇴직율 = 사유별 퇴사자 ÷ 전사 평균 재직인원 (분모 = 재직인원)
연환산 퇴직율 = 퇴직율 × 365 ÷ 기간 일수        (진행 중인 연도)
```

분모가 0이면 값을 내지 않고 `—` 로 표시합니다. 템플릿의 `IF(...=0,"")` 와 같습니다.

대시보드는 여기에 더해 **연평균 재직인원 10명 미만인 조직·직급을 퇴직율 순위에서 제외**합니다
(`최소분모` 상수). 분모가 한 자릿수면 퇴사 한두 명으로 퇴직율이 100%를 넘겨 순위가 무의미해지기
때문이며, 제외된 항목도 화면의 `[표]` 보기에서는 그대로 보입니다.

## 알려진 데이터 품질 이슈

현재 `퇴직율_분석_raw.xlsx` (1,147행 · 퇴사자 425명) 기준입니다.
이전에 있던 `본부`/`부서`/`직급`/`직군` 결측과 `부서` 덮어쓰기는 모두 해소됐습니다.

1. **`퇴사사유` 가 2025년부터만 입력돼 있습니다.** 2024년 퇴사자 149명은 전원 미입력이라
   `④ 퇴사사유` 와 `자발적 퇴직율` KPI는 **2025~2026 2개년만** 집계합니다.
   2024년 사유를 채우면 대시보드의 `사유연도수` 를 3으로 올려 3개년으로 넓힐 수 있습니다.
2. ~~`코드설정` 에 사유구분 열이 없음~~ → **해결.** `코드설정!K열(구분)` 에서 읽습니다.
   `자발`/`자발적`, `비자발`/`비자발적` 표기는 모두 인식하며, 빈 칸은 생성기의
   `기본_사유구분` 으로 넘어갑니다. `기준설정` 시트가 있으면 그쪽 L·M열이 항상 우선합니다.
3. **워크북에 `기준설정` 시트가 없습니다.** 그래서 기준일은 **실행 시점의 오늘 날짜**로,
   근속구간·직급그룹 매핑은 생성기 기본값으로 동작합니다.
   기준일을 고정하려면 `--기준일 2026-08-26` 을 넘기세요. YTD·연환산이 이 값에 좌우됩니다.

## 템플릿 워크북 이슈

`퇴직율_분석_템플릿_2022-2026.xlsx` 자체에도 수정이 필요합니다.

- **`①_본부별_퇴직율`** : 표1·2·3 본문이 헤더 아래(11·52·93행)가 아니라 **641~758행**에 생성됨.
  헤더 밑은 비어 있고 `전사 합계` 는 `#VALUE!`
- **`③_직급별_퇴직율`** : 직급그룹 표1·2·3 본문 없음. 직급상세 본문이 89~137행과 **699~816행**에 분산.
  108행은 `[표5]` 제목 셀에 수식이 겹침
- **`④_퇴사사유별_퇴직율`** : 표1·2·3 본문이 **243~316행**으로 밀림 (표4·5·6은 정상)
- `기준설정` L25·L26 이 비었는데 M25·M26 에 `비자발적` 이 있음 (계약만료·정년퇴직 누락 추정)
- `기준설정` C4 가 기본값 `2026-12-31` — 안내문대로 실제 기준일로 바꿔야 YTD·연환산이 의미를 가짐
- `②_근속구간별_퇴직비중` 과 `종합대시보드` 는 정상

이 대시보드는 워크북의 **계산 결과 셀을 읽지 않고 RawData에서 직접 재계산**하므로,
위 이슈와 무관하게 올바른 값을 냅니다.
