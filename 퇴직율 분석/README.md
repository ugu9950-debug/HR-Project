> ### ⚠ 이 폴더는 공개 저장소에 올리지 마세요
> 대시보드에는 본부별 재직인원·퇴직율 같은 **내부 인사 데이터**가 들어 있고,
> 원본 워크북에는 **임직원 성명이 포함된 개인정보**가 있습니다.
> `HR-Project` 저장소는 현재 **public** 입니다. 푸시 전에 저장소를 private 으로 바꾸거나,
> 이 폴더를 별도 비공개 저장소로 분리하세요.
> `.gitignore` 가 `*.xlsx` 를 제외하고 있으니 **워크북 자체는 커밋되지 않습니다.**

## 데이터 갱신

워크북을 최신화한 뒤 아래 한 줄이면 대시보드 숫자가 전부 바뀝니다.
**Node 18 이상만 있으면 되고, 설치할 패키지가 없습니다.**

```bash
node tools/build-dashboard-data.mjs 퇴직율_분석_템플릿_2022-2026.xlsx
```

`turnover_dashboard_prototype.jsx` 안의 `GENERATED-DATA` 구간만 교체하고,
정합성 검증 결과와 연도별 요약을 출력합니다. 검증에 실패하면 종료 코드 1을 반환합니다.

### 옵션

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--기준일 2026-08-25` | 재직자 근속·당해연도 기말의 기준일 | 워크북 `기준설정!C4`, 없으면 오늘 |
| `--연도 2024-2026` | 분석 기간 (현재 대시보드는 2024~2026) | 워크북 `기준설정!7행`, 없으면 최근 5년 |
| `--본부최소 5` | 연평균 재직인원이 이보다 작은 본부는 `기타(미매핑)` 로 합산 | 5 |
| `--교차표 12` | 본부 × 근속구간 교차표에 넣을 본부 수 | 12 |
| `--직급상세 20` | 직급 상세 표에 넣을 직급 수 | 20 |
| `--연령구간 25,30,35` | 연령대 경계 나이 목록 (§5·§6) | `30/40/50` (10세 단위, 50세 이상 통합) |
| `--제외사번 1234,5678` | 분석에서 통째로 뺄 사번. `""` 를 넘기면 아무도 빼지 않음 | 생성기의 `기본_제외사번` |
| `--keep-reasons` | 퇴사사유가 비어 있어도 기존 사유 블록을 유지 (데모용) | 꺼짐 |
| `--out <경로>` | 교체할 JSX 경로 | `../turnover_dashboard_prototype.jsx` |
| `--dry-run` | 파일을 쓰지 않고 리포트만 출력 | 꺼짐 |

생성기는 **RawData 1행의 헤더 이름으로 열을 찾습니다.** 열 순서가 달라도,
raw 레이아웃이든 템플릿 레이아웃이든 동작합니다.
필수 열은 `본부` · `직급` · `입사일` · `퇴사일` 이고,
`퇴사사유` · `생년월일` · `사원구분` 은 있으면 씁니다 (`생년월일` 이 있어야 §5·§6 연령 분석이 나옵니다).
`기준설정` 시트가 있으면 근속구간 상한(I·J), 직급그룹 매핑(D·E), 사유구분(L·M), 연령구간(O·P)을 읽고,
없으면 템플릿 표준값으로 대체합니다.

## 계산 정의 (템플릿과 동일)

```
퇴직율        = 해당 연도 퇴사자 수 ÷ 평균 재직인원
평균 재직인원 = (기초 재직인원 + 기말 재직인원) ÷ 2
기초 재직인원 = 1월 1일 시점 재직자
기말 재직인원 = 12월 31일 또는 데이터 기준일 시점 재직자
근속일수      = 퇴사자는 퇴사일 − 입사일, 재직자는 기준일 − 입사일
근속구간      = 상한(일) 이하를 만족하는 첫 구간
연령          = 만나이. 분모(재직 스냅숏)는 기초일·기말일 시점, 분자(퇴사자)는 퇴사일 시점
연령구간      = 상한(세) 이하를 만족하는 첫 구간
구성비        = 해당 연도 퇴사자 중 비율        (분모 = 퇴사자 수)
사유별 퇴직율 = 사유별 퇴사자 ÷ 전사 평균 재직인원 (분모 = 재직인원)
연환산 퇴직율 = 퇴직율 × 365 ÷ 기간 일수        (진행 중인 연도)
```

분모가 0이면 값을 내지 않고 `—` 로 표시합니다. 템플릿의 `IF(...=0,"")` 와 같습니다.

대시보드는 여기에 더해 **연평균 재직인원 10명 미만인 조직·직급을 퇴직율 순위에서 제외**합니다
(`최소분모` 상수). 분모가 한 자릿수면 퇴사 한두 명으로 퇴직율이 100%를 넘겨 순위가 무의미해지기
때문이며, 제외된 항목도 화면의 `[표]` 보기에서는 그대로 보입니다.

`⑦ 부서별 퇴직율` 은 예외입니다. 소표본 합산도 상위 N 자르기도 없이 **전 조직을 그대로** 싣기
때문에 합계가 항상 전사와 정확히 맞습니다. 대신 인원이 한 자릿수인 부서는 퇴직율이 쉽게 100%를
넘으므로 반드시 `평균인원` 을 함께 보세요. 표시 순서는 본부가 조직도 순서(`본부순서` 상수),
부서가 **코드포인트 오름차순**(엑셀 기본 텍스트 정렬 — 영문 팀이 한글 팀보다 앞)입니다.
선택한 연도에 재직자도 퇴사자도 없는 부서는 화면에서 숨깁니다.

## 퇴직사유 필터 (전체 / 자발적 / 비자발적)

대시보드 최상단 필터 행에서 고르면 **모든 섹션(§0~§7)의 분자(퇴사자)가 그 구분으로 다시 집계**됩니다.
KPI, 본부·근속·직급·연령·사원구분·부서 순위, 근속 교차표, 조직 트리까지 전부 따라 바뀝니다.

```
자발적 퇴직율 = 자발적 퇴사자 ÷ 전사 평균 재직인원
```

**분모는 구분과 무관하게 전사 평균 재직인원 그대로**입니다. 자발적 퇴사자를 "자발적 재직인원"으로
나눌 수는 없기 때문이고, 기존 `자발적 퇴직율` KPI와 같은 정의입니다. 덕분에
`자발 퇴직율 + 비자발 퇴직율 = 전체 퇴직율` 이 성립합니다 (사유 미입력분 제외).

### 연도 범위가 좁아집니다

퇴사사유는 **2025년부터만** 집계하므로(위 [데이터 품질 이슈] 1번), 자발/비자발을 고르면
분석 연도 선택지에서 2024년이 빠지고 `종합` 도 2개년 종합이 됩니다.
2024년을 남겨 두면 사유가 없는 해가 "자발적 퇴사 0명 → 퇴직율 0%"로 읽혀
**있지도 않은 개선을 보고하게 되기 때문**입니다. 2024년을 보던 중 필터를 켜면 최신 연도로 보정됩니다.

### 예외 — §4 [사유구분별 퇴사자 추이]

이 카드만 필터를 따라가지 않습니다. 자발 vs 비자발 **비교 자체가 목적**인 차트라 한쪽만 남기면
쓸모가 없어지기 때문입니다. 대신 선택한 구분을 진하게, 나머지를 흐리게 표시합니다.

### 생성기가 내보내는 데이터

생성기는 `cnt`(전체 퇴사자) 옆에 `k[구분 인덱스][연도 인덱스]` 를 함께 냅니다.
구분 인덱스 순서는 생성기의 `KINDS` 상수(`["자발적","비자발적"]`)이고,
JSX의 `KIND_KEYS` 와 **순서가 같아야 합니다**.

| 배열 | 추가된 필드 |
|---|---|
| `종합` | `퇴사구분` · `평균근속년구분` |
| `본부` · `직급그룹` · `직급상세` · `연령` · `사원구분` | `k` |
| `근속` | `k` |
| `본부X근속` | `k[구분][근속구간][연도]` (3차원) |
| `조직` (본부·부서) | `k` |
| `평균퇴사연령구분` | (신규 배열) |

`기타` 와 `사유 미입력` 은 따로 내보내지 않고 화면에서 `전체 − 자발 − 비자발` 로 계산합니다.
생성기는 차원별 자발/비자발 합이 전사 구분 합과 맞는지도 정합성 검증에서 확인합니다.

## 알려진 데이터 품질 이슈

현재 `퇴직율_분석_raw.xlsx` (1,107행 · 제외 1명 → 집계 대상 1,106행 · 퇴사자 403명) 기준입니다.
이전에 있던 `본부`/`부서`/`직급`/`직군` 결측과 `부서` 덮어쓰기, `생년월일` 결측은 모두 해소됐습니다.

1. **`퇴사사유` 는 2025년부터만 집계합니다 — 확정된 방침입니다.** 2024년 퇴사자 129명은
   사유를 입력하지 않기로 했으므로, `④ 퇴사사유` · `⑥ 연령대 × 퇴사사유` 와 `자발적 퇴직율` KPI는
   **2025~2026 2개년 고정**입니다. `①~③` `⑤` 는 2024~2026 3개년 전체를 그대로 씁니다.
   화면에서 2024년을 선택하면 ④·⑥은 "집계 구간 밖" 안내가 뜹니다 — 결측이 아니라 설계입니다.
2. ~~`코드설정` 에 사유구분 열이 없음~~ → **해결.** `코드설정!K열(구분)` 에서 읽습니다.
   `자발`/`자발적`, `비자발`/`비자발적` 표기는 모두 인식하며, 빈 칸은 생성기의
   `기본_사유구분` 으로 넘어갑니다. `기준설정` 시트가 있으면 그쪽 L·M열이 항상 우선합니다.
3. **워크북에 `기준설정` 시트가 없습니다.** 그래서 기준일은 **실행 시점의 오늘 날짜**로,
   근속구간·직급그룹 매핑은 생성기 기본값으로 동작합니다.
   기준일을 고정하려면 `--기준일 2026-08-26` 을 넘기세요. YTD·연환산이 이 값에 좌우됩니다.
4. ~~`생년월일` 이 `--` 로 들어온 행 2건~~ → **해결.** 잘못된 데이터로 확인돼 RawData에서 삭제했습니다.
   현재 생년월일 결측은 0건입니다. (다시 생기면 생성기가 `(생년월일 미상)` 구간으로 따로 셉니다.)
5. **사번 `13040104` 을 분석에서 제외했습니다.** 생년월일 `1948-09-15` · 퇴사 시점 만 77세로,
   차상위 최고령(65세)과 12년이나 벌어진 특이케이스입니다. 생성기의 `기본_제외사번` 에
   사유와 함께 적혀 있고, 재직·퇴사·연령 등 **모든 집계에서 빠집니다**. 되살리려면
   `--제외사번 ""` 를 넘기거나 `기본_제외사번` 에서 지우세요.
   생성기는 15세 미만·70세 초과 인원을 경고로 계속 알려 줍니다.
6. **`코드설정` 에 `사원구분` 목록 열이 없습니다.** 현재 값은 `정규직` 1,086 · `계약직` 21이며
   드롭다운 검증 없이 자유 입력이라 표기가 흔들리면 별도 항목으로 잡힙니다.
7. **워크북 내장 집계 시트가 낡은 범위를 참조합니다.** `종합대시보드` · `①_조직별_퇴사율` 등의
   수식이 `RawData!$A$2:$A$978` 을 보는데 실제 데이터는 1108행까지라 **130행이 빠집니다.**
   이 대시보드(JSX)는 전체 행을 직접 읽으므로 영향이 없지만, 엑셀 시트 숫자와 비교할 때는
   이 범위를 먼저 늘려야 합니다.

## 템플릿 워크북 이슈

`퇴직율_분석_템플릿_2022-2026.xlsx` 자체에도 수정이 필요합니다.

- **`①_본부별_퇴직율`** : 표1·2·3 본문이 헤더 아래(11·52·93행)가 아니라 **641~758행**에 생성됨.
  헤더 밑은 비어 있고 `전사 합계` 는 `#VALUE!`
- **`③_직급별_퇴직율`** : 직급그룹 표1·2·3 본문 없음. 직급상세 본문이 89~137행과 **699~816행**에 분산.
  108행은 `[표5]` 제목 셀에 수식이 겹침
- **`④_퇴사사유별_퇴직율`** : 표1·2·3 본문이 **243~316행**으로 밀림 (표4·5·6은 정상)
- `기준설정` L25·L26 이 비었는데 M25·M26 에 `비자발적` 이 있음 (계약만료·정년퇴직 누락 추정)
- `기준설정` C4 가 기본값 `2026-12-31` — 안내문대로 실제 기준일로 바꿔야 YTD·연환산이 의미를 가짐
- `②_근속구간별_퇴직비중` 과 `종합대시보드` 는 정상

이 대시보드는 워크북의 **계산 결과 셀을 읽지 않고 RawData에서 직접 재계산**하므로,
위 이슈와 무관하게 올바른 값을 냅니다.
